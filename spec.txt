1. Título del Proyecto 
Proyecto de Desarrollo de un Sistema de Automatización de Solicitudes Internas de 
Personal 
2. Tecnologías / Herramientas / Metodologías Aplicables  
Python, FastAPI, React.js, Azure OpenAI Service, PostgreSQL, Redis, Docker, GitHub Actions, 
Microsoft Entra ID, Power BI y Scrum. 
3. Delimitación del Proyecto  
La solución automatizará la gestión de solicitudes internas relacionadas con Recursos 
Humanos, como vacaciones, permisos, constancias, cambios de información, incidencias y 
aprobaciones. Incorporará flujos de trabajo, reglas de negocio, notificaciones y agentes 
inteligentes para agilizar la atención y reducir tiempos operativos. 
4. Objetivos 
Objetivo General: 
Desarrollar un sistema inteligente para automatizar las solicitudes internas de personal. 
 
Objetivos Específicos: 
• Analizar los procesos actuales. 
• Diseñar la arquitectura tecnológica. 
• Implementar flujos automatizados y agentes inteligentes. 
• Validar la operación. 
• Documentar la solución y el plan de soporte. 
5. Justificación 
Impacto en la Industria: Optimiza la atención de solicitudes internas mediante 
automatización. 
 
Valor para PluriOne: Fortalece el portafolio HRTech con soluciones de workflow inteligente. 
 
Desarrollo del Alumno: Desarrolla competencias en automatización de procesos, 
arquitectura empresarial e inteligencia artificial.
